Coupons

Honour a code

Merchandise coupons are shown in person. Entry coupons are entered by the player on Disc Golf Scene — add them to the event first (see below), then mark them used here once the entry list shows them. Look a code up to check it is live, then mark it used. Marking used cannot be undone.

Two on one purchase. A player may put 2 codes of the same kind together. Enter both below and either both are marked used or neither is — that is the record. Delivering the discount differs by kind: for merchandise take $10 off at the counter; for an entry, add a single $10 code to Disc Golf Scene instead of two $5 ones, since a registration takes one code.

Disc Golf Scene setup

Before an event, add each live entry coupon to the Disc Golf Scene listing under Discount codes → Add a code. Set Max uses 1 so DGS enforces single use, and set Email to the player's, so a code that gets shared is useless to anyone else. DGS applies codes to the division entry fee only, not add-ons. To honour two coupons on one entry, add a single $10 code instead and mark both used here.
