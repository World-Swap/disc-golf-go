# Grants — where the material lives

The grant work is **not in this repo, and should not be put in it.** The kit
opens with the company's EIN and the founder's home address, and
`World-Swap/disc-golf-go` is a **public** repository — committing it would
publish both permanently, since git history keeps them after any later
deletion. This file is the pointer so the next session does not have to go
looking, which is the whole reason it exists: nothing outside this repo
survives a session.

## Where

Google Drive → **`DiscGolfGo/DiscGolfGo-Grants/`** (owner: orionsun83@gmail.com).
Markdown is the working copy; the parent `DiscGolfGo/` folder holds a Google Doc
export of each, which is what gets pasted into application forms.

| File | What it is |
| --- | --- |
| `GRANT-KIT.md` | The main kit. Business fact sheet, reusable application copy for Venmo, FedEx, Hello Alice and NASE, and the groundwork for the NSF pitch |
| `NSF-PROJECT-PITCH.md` | NSF SBIR Project Pitch draft — AI/computer-vision analysis of a disc golf throw from a single phone video |
| `ADVISOR-OUTREACH.md` | Approach for finding a CV/ML advisor |
| `ADVISOR-LETTER-OF-SUPPORT.md` | Letter-of-support template for that advisor |

## The one date that matters

**SAM.gov registration renews 2027-09-24.** Start it around **late July 2027** —
a lapsed registration makes you ineligible mid-application and re-validation
runs to weeks, not days.

## Known stale

2026; pending Active"*. It is **active** — the confirmation arrived with a CAGE

## If you are a future session asked to work on this

Read the files from Drive, work from them, and write results back to Drive.
Do not paste the fact sheet into this repo, into the promo site, or into any
commit message. Business identifiers belong in Drive; this file holds the
pointer and the deadline, and nothing else.
